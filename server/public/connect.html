Shopify (custom app with access token)
Store admin > Settings > Apps > Develop apps > your app > API credentials.
BigCommerce
Install StockSense from the BigCommerce App Marketplace, or via your draft app install link. You will land back here automatically.
BigCommerce (API account with access token)
Control panel > Settings > API > Store-level API accounts. Needs Products and Orders read-only.
WooCommerce
WooCommerce > Settings > Advanced > REST API > Add key (Read access).
